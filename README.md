# running

富士山マラソン 2026（12/14）訓練課表與紀錄。

- 📱 手機看這裡：**https://iamwuwei.github.io/running/**
- `富士山馬拉松_2026_課表.xlsx`：資料來源
  - 工作表「課表」：每日計畫與實際紀錄（A〜U），加上人工判定 V「判定」、W「提醒」
  - 工作表「週總覽」：每週計畫 / 實際 km、達成率、重點（公式）
- `build_site.py`：從 xlsx 產生 `docs/index.html`（今天、下次練習、最新報告、週進度、歷史紀錄）。網頁只渲染，不做任何自動判定。
- `.github/workflows/pages.yml`：push 到 main 時自動重新產生並部署到 GitHub Pages

## 欄位

| 欄 | 內容 |
|---|---|
| A〜I | 週、日期、星期、階段、類型、計畫 km、配速/心拍、內容、備註（課表） |
| J〜U | 實際 km、完成、心得、時間、平均配速、平均心拍、最大心拍、平均功率 W、卡路里、天氣、鞋、裝置 |
| V | 判定：`達成` / `達成但有提醒` / `未達成` / `跳過`，空白＝尚未評 |
| W | 提醒：多條用「｜」分隔，空白＝無 |

網頁的執行結果區塊：標題＝V 欄文字；底色 達成＝綠、達成但有提醒＝黃、未達成＝紅、跳過＝灰；條列＝W 欄用「｜」切開；V 空白則不顯示此區塊。

## 更新指令格式

每次更新用這個格式，列全部用 B 欄日期比對，未提到的欄位不動，不自行解讀：

```
日期：J, K, L, M, N, O, P, Q, R, S, T, U, V, W
```

填完後：LibreOffice 重算 → `python3 build_site.py` → xlsx 與 `docs/index.html` 一起 commit 到 main → 列出改動的儲存格。
